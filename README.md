# Практические работы по Java

Мои практические работы по Java во 2 курсе, РТУ МИРЭА. Каждая практика лежит в своём пакете, внутри несколько небольших программ.

## Что здесь есть

- Основы Java: массивы, циклы, строки, работа с Git
- Классы и объекты, конструкторы, наследование, абстрактные классы
- Интернет-магазин и магазин мебели (классы, массивы, enum)
- Интерфейсы: перевод температуры, операции над строками
- Рекурсия (простые числа, разложение на множители, палиндром)
- Сортировки: вставками, быстрая, слиянием, Comparable и Comparator
- Дата и время: Date, Calendar, SimpleDateFormat
- Обработка строк: String, StringBuilder, split, StringTokenizer
- Регулярные выражения: Pattern и Matcher

## Как запустить

Открыть проект в IntelliJ IDEA и запустить нужный класс с методом main.
В задании про цепочку слов программа читает слова из файла. Файл нужно положить в папку, откуда запускается программа, и ввести его имя при запросе.
